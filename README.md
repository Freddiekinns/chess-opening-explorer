# Chess Opening Explorer

**Live at [openingbook.vercel.app](https://openingbook.vercel.app)**

A chess learning platform for exploring and practising openings. Features 12,377+ openings with AI-enhanced content, Lichess statistics, curated videos, and interactive practice mode.

## Features

- **Fast Search**: 1-5ms client-side filtering with popularity-weighted ranking
- **Practice Mode**: Interactive move trainer with hints, feedback, and Lichess-style visual indicators
- **Personal Opening Explorer**: Analyse your Chess.com/Lichess games to find strengths and weaknesses
- **PGN Identification**: Paste any PGN to identify the opening
- **AI Content**: Strategic analysis and complexity ratings via Google Vertex AI
- **Video Integration**: Curated YouTube content from trusted chess channels
- **Popularity Stats**: Win/draw/loss rates from 40M+ Lichess games

## Quick Start

```bash
# Install dependencies
npm install

# Import ECO data
npm run eco:import

# Start development servers
npm run dev
```

- Frontend: http://localhost:3000
- API: http://localhost:3010

## Data Pipelines

### LLM Enrichment
```bash
node tools/llm-enrichment/enrich_openings_llm.js
```
Generates strategic descriptions via Google Vertex AI. Supports batch processing, dry-run, and resumable runs.

### Popularity Stats
```bash
cd tools/analysis && python run_pipeline.py
```
Processes Lichess game data to calculate opening statistics.

### Video Pipeline
```bash
node tools/video-pipeline/index.js
```
Discovers and matches YouTube videos from trusted channels.

## Architecture

**Unified codebase**: Development and production use identical business logic. Vercel functions are thin wrappers (~40 lines) that import from `packages/api`.

**Single CSS file**: All styles in `packages/web/src/styles/simplified.css`.

**Pre-processed data**: JSON files generated by pipelines, served statically for fast client-side search.
